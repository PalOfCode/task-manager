# 📋 Task Manager

A modern and responsive Task Manager web application built using HTML, CSS, and JavaScript.

Task Manager helps users create, manage, organize, and track their daily tasks through a clean and user-friendly dashboard.

---

## 🚀 Live Demo

🔗 https://palofcode.github.io/task-manager/

---

## ✨ Features

### 🔐 Authentication
- User Registration
- User Login
- Forgot Password
- Password Reset
- Logout
- Remembered user session

### 📋 Task Management
- Add new tasks
- Edit existing tasks
- Delete tasks
- Mark tasks as Completed
- Move tasks between Pending and In Progress
- Search tasks
- Filter tasks by status
- Filter tasks by priority
- Due date support

### 📊 Dashboard
- Total Tasks
- Pending Tasks
- In Progress Tasks
- Completed Tasks
- Overdue Tasks
- Task completion statistics
- Dashboard analytics

### 👤 Profile
- View profile information
- Update name
- Change password
- Profile avatar
- Account logout

### ⚙️ Settings
- Dark Mode / Light Mode
- Notification settings
- Default task priority
- Clear all tasks
- Account management

### 🎨 UI/UX
- Responsive design
- Toast notifications
- Empty task state
- Interactive buttons
- Clean dashboard interface
- Dark mode support
- User-friendly navigation
